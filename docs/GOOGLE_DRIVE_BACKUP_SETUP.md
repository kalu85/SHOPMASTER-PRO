
## Google Drive backup setup (Android)

The app now includes a Google Drive backup and restore screen. It uses Google Sign-In
with the restricted `drive.file` scope and stores app-created SQLite backup files in a
folder named `SHOPMASTER PRO Backups`. The user must tap **Connect Google Drive** and
**Back up to Drive**; cloud upload is not automatic. Restore requires confirmation,
downloads the selected file, verifies SQLite integrity, and creates a local safety
backup before replacing current data.

Before Drive sign-in can work on a distributed APK, configure Google Cloud:

1. Create/select a Google Cloud project and enable **Google Drive API**.
2. Configure the OAuth consent screen for the intended audience and add the app's
   requested test users if the consent screen is in testing mode.
3. Create an **Android OAuth client** using the app's actual Android application ID
   and the SHA-1 fingerprint of the certificate that signs the installed APK.
4. The current GitHub workflow generates the Android project during the build and
   uses Flutter's default debug signing when no release keystore is configured.
   Therefore a stable production release needs an owner-controlled signing key and
   matching OAuth Android client. Do not commit signing keys or passwords.
5. Rebuild and install the APK signed with that configured certificate, then test
   Connect, upload, list, download and restore with a non-production test database.

Current application ID generated by the workflow: `com.shopmaster.shopmaster_pro`.
The package ID and signing certificate must match the OAuth client exactly. OAuth
configuration is not embedded in this source-only change, so Drive sign-in must not
be described as live until the owner configures the Cloud project and a signed APK
passes an end-to-end test. Never share Google passwords or one-time codes.

The app only uploads when the user explicitly taps the upload button. A local backup
is created first; the local database is not deleted by uploading. Drive files are
ordinary files in the user's Drive account, so users should protect their Google
account and understand that this backup contains shop/customer business records.
